## Зачем этот проект

Печатать текст — значит терять ход мысли. NovaWhisper предлагает диктовку
вместо этого: зажмите глобальную горячую клавишу, говорите в любом
приложении — и обработанный текст вставится точно в позицию курсора, без
переключения между отдельным приложением для диктовки и тем, в котором вы
на самом деле работаете.

Проект сделан так, чтобы диктовка оставалась приватной и гибкой, а не
привязывала вас к одному облачному провайдеру: распознавание речи может
работать полностью офлайн на локальной модели Whisper либо использовать
Deepgram, если нужно облачное качество. Перед вставкой текст проходит этап
обработки — убираются слова-паразиты и запинки.

Поддерживается уже сейчас: Windows 11 (основная цель, с ускорением NVIDIA
CUDA), macOS на Apple Silicon и Linux (X11/XWayland).

## Как это устроено

NovaWhisper состоит из двух процессов:

1. Rust/Tauri **desktop-приложение** записывает микрофон, показывает HUD и
   вставляет текст в активное приложение.
2. Python/FastAPI **gateway** выполняет распознавание речи (mock / локальный
   Whisper / Deepgram) и обрабатывает расшифровку.

Управлять gateway вручную обычно не нужно: приложение запускает его при
старте и останавливает при выходе, используя встроенный sidecar
`whispr-gateway` в сборках-установщиках или `server/gateway/.venv` в сборке
из исходников. Уже запущенный вручную gateway приложение обнаруживает и не
трогает. Подробнее о дизайне — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)
(на английском).

Пользовательский сценарий: **настроить и сохранить → запустить и
произнести → остановить и автоматически распознать → получить и
использовать текст**, при этом каждая расшифровка также сохраняется в
Voice clipboard внутри приложения.

## Быстрый старт (из исходников)

```sh
# 1. Gateway (Python)
cd server/gateway
python3 -m venv .venv   # на Windows: py -m venv .venv
./.venv/bin/pip install -r requirements.txt          # mock/dev-провайдеры
./.venv/bin/pip install -r requirements-local.txt    # + локальный Whisper (опционально)

# 2. Desktop-приложение (Rust) — из корня репозитория; само запускает и останавливает gateway
cargo run -p whispr-desktop
```

Затем в Settings: выберите микрофон, язык, провайдер распознавания и
горячую клавишу, сохраните и дождитесь готовности gateway.

Здесь описан только базовый случай. Пошаговую установку на чистый
Windows/CUDA, настройку macOS Apple Silicon, системные пакеты для Linux,
автономные установщики и решение проблем смотрите в
**[docs/INSTALL.md](docs/INSTALL.md)** (на английском).

## Структура репозитория

| Путь | Назначение |
|---|---|
| `core/` | Аудио, протокол, VAD, конфигурация и streaming client на Rust |
| `platform/insert/` | Вставка текста в другие приложения |
| `apps/desktop/` | Tauri desktop-приложение и интерфейс |
| `server/gateway/` | FastAPI gateway, STT-провайдеры и обработка текста |
| `scripts/` | `build-gateway.sh` / `.ps1` — сборка автономного sidecar gateway |
| `shared/protocol.md` | Протокол между клиентом и gateway |
| `docs/` | Установка, архитектура, структура и инструкции разработчика |
