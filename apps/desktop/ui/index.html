Whispr

Voice to text, anywhere. Press the global hotkey in any app to dictate.

The selected microphone is used the next time dictation starts.
When enabled, the app launches the speech gateway on startup and stops it on quit. A gateway that is already running is used as-is and never stopped.
Saving these restarts the managed gateway. The first start of a new model downloads it (large-v3 ≈ 3 GB).
